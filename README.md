# Everypane

A file manager for Windows, WSL, and SSH work.

Visit [everypane.app](https://everypane.app/) for the product tour and release status.

The Windows beta is in preparation. Downloads will appear under [Releases](https://github.com/geointelmining848/everypane/releases) after release checks are complete.

This repository hosts downloads and bug reports. Application development uses a separate private repository.

## Report a problem

Open an issue with the Everypane version, Windows version, steps, and exact error text.
Remove passwords, private keys, confidential file contents, and private paths before posting.
